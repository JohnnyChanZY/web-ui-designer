# 🎨 Web UI Design Prompt Generator

一个帮助你快速生成网站 UI 设计 prompt 的工具。选择你想要的 UI 元素，一键生成专业的设计描述，直接复制粘贴给 AI 使用。

## ✨ 功能特性

- **🧭 导航栏选择** — 顶部固定、侧边栏、汉堡菜单、超级菜单、标签栏、浮动导航
- **📐 布局模式** — 单列、双栏、网格、瀑布流、仪表盘、着陆页
- **🎨 颜色方案** — 8 种预设配色 + 自定义颜色选择器
- **🔤 字体风格** — 现代无衬线、经典衬线、科技等宽、圆润友好、粗体醒目、优雅细体
- **✨ 视觉风格** — 极简、毛玻璃、新拟态、粗野主义、渐变、扁平化
- **🧩 组件风格** — 按钮样式 + 卡片样式
- **⚡ 附加特性** — 暗色模式、微动效、响应式、渐变、阴影、图标系统
- **📋 一键复制** — 生成的 prompt 直接复制到剪贴板
- **🖥️ 实时预览** — 右侧 mini 预览实时反映你的选择

## 🚀 使用方式

直接在浏览器中打开 `index.html` 即可使用，无需安装任何依赖。

```bash
# 或者使用任何静态文件服务器
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

## 📸 使用流程

1. 在左侧面板选择你想要的 UI 元素（导航、布局、颜色等）
2. 右侧面板会实时生成设计 prompt
3. 点击「📋 复制」按钮
4. 将 prompt 粘贴到任何 AI 工具中使用

## 🛠️ 技术栈

- 纯 HTML + CSS + JavaScript
- 无框架依赖，零构建步骤
- 响应式设计，支持移动端
